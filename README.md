# Weekly Todo Ball / 每周待办悬浮球

一款面向 Windows 的离线单机待办工具：按周记录任务、勾选完成状态，并可缩小为可拖动的桌面悬浮球。无需账号、无需联网，所有个人待办只保存在当前电脑。

## 直接使用

1. 下载或克隆本仓库。
2. 双击运行 dist/WeeklyTodo.exe。
3. 在输入框填写待办，按 Enter 或点击“添加”。

程序为单文件 EXE，无需安装 Python 或额外依赖。

## 主要功能

- **按周管理**：可切换前后周，或通过日历选择任意日期；程序自动跳转到该日期所在的周。
- **圆圈勾选**：点击任务左侧圆圈即可标记完成；已完成任务会自动排到列表后方。
- **自动延续**：打开下一周时，上周未完成的任务会自动带入一次；已完成任务不会重复带入。
- **本周导出**：导出当前周已完成任务，文本按 1. 2. 3. 编号，使用 UTF-8 编码。
- **历史查询**：可按日期或任务内容查询以往周的待办记录。
- **桌面悬浮球**：
  - 窗口最小化后自动变为悬浮球；
  - 按住可拖动到任意屏幕位置；
  - 单击展开完整的本周任务卡片；
  - 双击回到完整编辑界面；
  - 根据所在屏幕角落向内侧展开，避免内容越出屏幕；
  - 悬浮球显示未完成数量、完成进度与当前状态。
- **更舒适的界面**：浅色圆角卡片、柔和边界、清晰层级与长文本省略号，适合长时间使用。

## 悬浮球使用说明

| 操作 | 结果 |
| --- | --- |
| 最小化主窗口 | 缩小为桌面悬浮球 |
| 拖动悬浮球 | 改变悬浮球位置 |
| 单击悬浮球 | 展开本周任务卡片 |
| 双击悬浮球 | 打开完整编辑窗口 |
| 展开卡片中的“收起” | 回到悬浮球 |
| 展开卡片中的“编辑” | 回到完整编辑窗口 |

## 数据与隐私

个人待办数据库保存在当前 Windows 用户目录：

~~~
%LOCALAPPDATA%\WeeklyTodoBall\todo.db
~~~

- 不需要登录，也不会上传或同步到云端。
- 更新 EXE 或重新下载仓库不会清空现有待办。
- 本仓库中的 data/todo.db 仅为空数据库模板，不含任何个人任务；程序实际运行时不使用该模板。

## 开发与打包

开发运行要求 Python 3.10+（含 Tkinter）：

~~~powershell
python weekly_todo.py
~~~

使用 PyInstaller 打包单文件 Windows 程序：

~~~powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed --name WeeklyTodo weekly_todo.py
~~~
